Ask us a question
What is free and unlimited?

The on-device AI models, local coding agent, editor, and four language runtimes are free. Local AI has no subscription usage cap. Optional cloud AI has a monthly usage limit; personal API connections are billed by your provider.

Which AI models power Edsger?

Edsger uses third-party models. Edsger 1.0 is powered by Qwen3.5-4B; Mini uses Liquid AI’s LFM2.5-1.2B-Instruct; Dijkstra is powered by DeepSeek. Edsger provides the app, model integration, project tools, local runtimes, and learning experience.

Why pay for Pro if the local AI is free?

Pro combines cloud AI with Edsger’s Chat and project tools, plus your own OpenAI or Claude API connections, GitHub push, photos in cloud Chat, and personalization. The free app remains a useful option on its own.

Can I use it without the internet?

Yes. After installing the app, on-device AI and the language runtimes work offline. Cloud AI, provider connections, GitHub push, and purchases require an internet connection.

Does local AI perform like a large cloud model?

Local models are smaller and their answers, speed, and memory use depend on the task and device. They can be useful for everyday questions and smaller programs. Complex work may benefit from a cloud model. Every model can make mistakes.

What programs can I run?

C uses PicoC, an interpreter rather than GCC or Clang. Python, JavaScript, and Lua run in restricted on-device environments. Package installation, desktop graphical interfaces, and network access from programs are not supported. Review AI-generated code and test it before relying on it.

What happens to my prompts and files?

Local AI processes your requests on your device. Optional cloud requests send relevant prompts, conversation context, documents, photos, project code, and tool results to the selected service after you allow sharing. Dijkstra uses Edsger’s service to connect to DeepSeek; personal API connections go to your chosen provider. GitHub receives the files you choose to push.

What happens when my cloud allowance runs out?

On-device AI remains available. Pro and Pro Plus include metered monthly cloud usage, and the app shows your remaining allowance. Allowances reset with your subscription period and do not roll over. A small balance can remain unusable if it cannot cover the reserve required to start another request.
