Code and learn on your iPhone and iPad.

Edsger runs C, Python, JavaScript, and Lua on your device, with a free on-device AI tutor. No account needed.

Free on the App Store. iPhone and iPad.

  • Runs on your device.
  • Free AI, offline.
  • No account.

Languages

  • C

    PicoC, a small interpreter, with its own projects, syntax highlighting, console input, and Stop.

  • Python

    Python 3.14 with the standard library.

  • JavaScript

    JavaScriptCore.

  • Lua

    Lua 5.5.

Editor

Each language has its own project. Write the program, then press Run. Stop a running program when you need to. Console input works in the editor. Projects stay on the device.

Chat

Ask it to explain code, fix an error, or walk through a math or science problem. Documents can be attached. Math answers are step by step. The free model stays on the device.

Agent

Describe a change. The agent reads, edits, and runs files in the project. It keeps restore points. You still press Run.

Limits

C runs in PicoC, not GCC or Clang, so some standard library features are missing. Python, JavaScript, and Lua run without package installs, network access, or a graphical interface. AI can make mistakes. Review its code, and do not rely on it for medical, legal, or financial advice.
