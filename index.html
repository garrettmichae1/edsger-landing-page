Limits

C runs in PicoC, not GCC or Clang, so some library features are missing. Python, JavaScript, and Lua run on the device, without package installs, network access, or a graphical interface. The AI can be wrong. Read what it writes, and do not use it for medical, legal, or financial decisions.
